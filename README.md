# arXiv 每日阅读

**gr-qc · hep-th｜摘要翻译 · 双语阅读卡 · 中文日报 · 研究精选**

每天北京时间 **11:00** 在云端启动检查和阅读，按完成情况于 **14:00–16:30** 将简报发送至 **1468610627@qq.com**。首次正式运行：**2026-10-29**。电脑离线时仍由云端执行，成果按日期保存在本仓库。

## 从这里开始

| 想做什么 | 入口 |
| --- | --- |
| 查看每日工作记录（含无更新与异常） | [工作日志](logs/README.md) |
| 阅读最新简报或查阅往期 | **[日报索引](reports/README.md)** |
| 查看或调整科研偏好 | [兴趣与科研关联](config/interests.md) |
| 查看时间、收件人和云端日程 | [运行配置](config/schedule.json) |
| 了解阅读、筛选和邮件规则 | [执行规程](docs/workflow.md) |
| 维护脚本与核对结果 | [维护说明](docs/maintenance.md) |

全部新文与首次交叉收录先按标题和摘要预分类，跨分类去重，修订稿单列。兴趣与科研关联均低且判断明确的文章跳过正文，保留标题、链接及理由；有兴趣、有科研用途或拿不准的进入阅读队列。阈值见 [预分类配置](config/triage.json)。

入选论文提供摘要中文翻译或明确标记的转述、基于正文的独立中英概括；每天生成中文综合简报和双语精选。跳过清单单列，不生成伪装成正文阅读的笔记。

**先核对是否更新，并与上一批逐篇比对 ID 和版本。** 如实列出需读正文、正文已读、仅摘要、待读及跳过数量；旧文不冒充新文；明确授权的补读单独标明。无更新也记录日志；未更新每 15 分钟复查，特殊原因未执行时 14:00 邮件告知。

## 目录

| 目录 | 保存内容 |
| --- | --- |

| `templates/` | [逐篇阅读卡模板](templates/paper.md) |

| `state/` | 运行状态、已读版本记录与邮件防重记录 |
| `scripts/`、`tests/` | 采集、校验工具及测试 |
| `archive/` | [初始化与迁移记录](archive/setup-2026-10-28/README.md)，不参与正式日报 |
