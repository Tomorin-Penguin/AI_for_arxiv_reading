# 官方数据

[返回首页](../README.md) · [阅读简报](../reports/README.md)

本目录按 `YYYY-MM-DD/manifest.json` 保存正式运行的论文公告清单、摘要元数据、版本与去重统计。日期为北京时间报告日期；清单中另保留来源公告日期。

元数据抓取成功不等于正文阅读完成。阅读卡和简报位于 `reports/`；已读状态以当日 `status.json` 为准。

2026-10-28 的初始化清单已移至 [归档](../archive/setup-2026-10-28/README.md)，不会作为 2026-10-29 或其他日期的正式输入。
