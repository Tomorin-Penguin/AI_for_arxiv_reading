## 如何阅读

- **中文简报**：当天主题、主要结果、阅读顺序与完整论文索引。
- **双语精选**：按兴趣与科研关联分组，给出中英概括、推荐理由及原论文链接。
- **逐篇阅读卡**：位于每期 `papers/` 中，记录摘要、翻译、独立理解与正文依据。
- **完成状态**：`complete` 为全部正文阅读完成；`partial` 为部分完成；`no_updates` 为已核实无新论文；`source_failed` 为来源失败。

逐篇状态分为 `body_reviewed`（已读正文）、`abstract_only`（仅摘要）和 `pending`（待读），三者不混算。报告进度以该日 `status.json` 为准，邮件实际发送记录另存于 `state/mail/`。
